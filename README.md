# edu-llama: AI Learning Assistant

edu-llama is a Streamlit app for studying with an AI tutor. It includes:

- **AI chat**, powered by free models on [OpenRouter](https://openrouter.ai/)
- **PDF study**: upload a PDF, get a summary, and ask questions about it
- **Interactive quizzes** generated by AI on any topic and difficulty
- **Voice input and output** through the microphone and text-to-speech
- **Engagement monitoring**: uses the webcam to detect emotions and warn when the student seems disengaged
- **Pomodoro focus timer**

---

## Requirements

| What | Version / notes |
|---|---|
| **Python** | **3.12** (required; see the note below) |
| OS | Tested on Windows 10/11. macOS and Linux should work with the differences noted below. |
| OpenRouter API key | Free: create one at <https://openrouter.ai/settings/keys> |
| Webcam and microphone | Optional; only needed for engagement monitoring and voice input |

> **Why Python 3.12?** Several of the pinned libraries (Pillow, NumPy, OpenCV, TensorFlow and others) have no prebuilt packages for Python 3.13 or 3.14. With those versions, `pip install` tries to build them from source and fails with errors such as `KeyError: '__version__'`. Python 3.12 installs everything from ready-made packages.

## Setup

### 1. Get the code

```bash
git clone https://github.com/arjun2004/edu-llama.git
cd edu-llama
```

### 2. Install Python 3.12

If you don't have it yet:

- **Windows:** `winget install -e --id Python.Python.3.12`, or download it from [python.org](https://www.python.org/downloads/release/python-31210/). You can keep a newer Python installed alongside it.
- **macOS:** `brew install python@3.12`
- **Linux (Debian/Ubuntu):** `sudo apt install python3.12 python3.12-venv`

Check that it's installed:

```powershell
py -3.12 --version        # Windows
python3.12 --version      # macOS / Linux
```

### 3. Create and activate a virtual environment

**Windows (PowerShell):**

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell says *"running scripts is disabled on this system"*, run this once and then try again:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

**macOS / Linux:**

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

When the environment is active, your prompt starts with `(.venv)`.

### 4. Install the dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements-exact.txt
```

`requirements-exact.txt` pins versions known to work with Python 3.12. `requirements.txt` contains looser version ranges if you'd rather get newer releases.

The download is large, mainly TensorFlow (used for emotion detection), so the first install takes a few minutes.

**PyAudio on macOS/Linux:** PyAudio needs the PortAudio system library. Install that first:

```bash
brew install portaudio                                 # macOS
sudo apt install portaudio19-dev python3-dev          # Debian/Ubuntu
```

### 5. Run the app

```bash
streamlit run app.py
```

Streamlit opens the app in your browser at <http://localhost:8501>.

### 6. Add your OpenRouter API key

1. Create a key at <https://openrouter.ai/settings/keys>. It starts with `sk-or-v1-`.
2. Paste it into **OpenRouter API Key** in the app's sidebar.
3. Pick a model under **🤖 Model Settings** and start chatting.

The key is kept only for your browser session. The Quiz page uses the same key, and you enter it again after refreshing the page.

## Using the app

| Feature | How to use it |
|---|---|
| Chat | Type in the chat box at the bottom of the main page. |
| PDF study | Sidebar → **📄 PDF Upload** → choose a PDF → **📂 Load PDF**. You can then ask questions about it. |
| Quiz | Sidebar → **🧭 Navigation** → **🧠 Interactive Quiz**. Choose a topic and difficulty. |
| Voice | Sidebar → **🎤 Voice Features** |
| Focus timer | Sidebar → **⏱️ Pomodoro Focus Timer** |
| Engagement monitoring | Sidebar → **📊 Engagement Monitoring** → **🎥 Enable Engagement Monitoring**. It uses the webcam. After 15 seconds of continuous disengagement (looking away, sad or bored expression, or no face), a pop-up suggests a quick quiz to chill. It shows at most once every 2 minutes. Use **🧪 Test Disengagement Alert** to preview it. |

You can also run the emotion detector on its own, in a desktop window:

```bash
python cv.py
```

## AI models

The app uses **free** models on OpenRouter. You can choose one in the sidebar:

- `google/gemma-4-31b-it:free` (default)
- `nvidia/nemotron-3-super-120b-a12b:free`
- `qwen/qwen3.8-27b:free`
- `z-ai/glm-5.2:free`
- `google/gemma-4-26b-a4b-it:free`

If the model you picked is busy or rate-limited, OpenRouter automatically tries the next ones in the list.

**Free model limits:** about 20 requests per minute, and **50 requests per day** unless you've bought at least $10 of OpenRouter credits (then 1,000 per day).

Free models change over time. If one stops working, check whether any provider still serves it:

```bash
curl https://openrouter.ai/api/v1/models/<model-id>/endpoints
```

An empty `"endpoints": []` list means no provider is serving it. Replace it in the `FREE_MODELS` list in `app.py`, and in `FALLBACK_MODELS` and the default model in `pages/quiz.py`. The full list of models is at <https://openrouter.ai/models>.

## Troubleshooting

| Error | Cause and fix |
|---|---|
| `KeyError: '__version__'` / `Failed to build 'Pillow'` during install | You're using Python 3.13 or newer. Use Python 3.12 in a virtual environment (setup steps 2–4). |
| `Cannot import 'setuptools.build_meta'` during install | The same cause: an old pinned package is being built from source. Use Python 3.12 and `requirements-exact.txt`. |
| **401** Unauthorized | OpenRouter rejected the API key. Check that it starts with `sk-or-v1-` and has no extra spaces. If it still fails, create a new key. |
| **404** Not Found in the app | The selected model is no longer available on OpenRouter. See [AI models](#ai-models). |
| **404** when opening the API link in a browser | This is normal. That address only accepts requests from the app, not browser visits. |
| **429** Too Many Requests | You hit a rate limit. Wait a minute, pick another model, or check whether the error mentions `free-models-per-day` (the daily limit resets each day). |
| `No module named 'pkg_resources'` | `setuptools` is 81 or newer. Run `pip install "setuptools<81"`. |
| Quiz shows *"Using fallback questions"* | The model's reply couldn't be used, or the request failed. Read the message above it for the reason, then try again or pick another model. |
| TensorFlow warnings about GPU or CPU instructions at startup | These are harmless. TensorFlow runs on the CPU on Windows. |
| Microphone or webcam not detected | Check your operating system's privacy settings and allow Python or your terminal to use the camera and microphone. |
